# Bam-kanladege

تطبيق بسيط وعملي لاستنساخ الصوت باستخدام Gradio و TTS، مع دعم التعرف التلقائي على لغة النص/الكلام، ويشمل دعم اللغة البامبارا (Bambara) ضمن اللغات المدعومة.

## ما الذي يفعله التطبيق؟
- يطلب منك رفع ملف صوتي مرجعي (3-10 ثواني)
- يطلب منك كتابة نص ليُقال
- يقوم بتحديد اللغة تلقائيًا إن أمكن
- يولّد ملف صوتي جديدًا بنفس نبرة الصوت المرجعي
- يدعم لغات متعددة، بما فيها البامبارا، مع إمكانية اختيار اللغة يدويًا

## المميزات
- استنساخ صوتي من ملف مرجعي
- توليد كلام من النص بنفس نبرة الصوت
- اكتشاف اللغة تلقائيًا
- دعم اللغات متعددة، مثل:
  - العربية
  - الإنجليزية
  - الفرنسية
  - الإسبانية
  - البامبارا (Bambara)
  - وغيرها حسب دعم النموذج المستخدم
- واجهة سهلة عبر Gradio

## المتطلبات
- Python 3.9+
- pip
- اتصال إنترنت أول مرة لتحميل النماذج
- (اختياري) GPU لتسريع العملية

## تثبيت المكتبات
```bash
pip install -r requirements.txt
```

إذا لم تكن المكتبات كاملة، يمكنك تثبيتها يدويًا:
```bash
pip install TTS gradio torch torchaudio soundfile
pip install langdetect
# اختياري: كشف لغة الصوت
pip install openai-whisper
```

## التشغيل
```bash
python app.py
```

ثم افتح الرابط الذي يظهر في الطرفية، عادةً:
- http://127.0.0.1:7860

## دعم اللغة تلقائيًا
يتضمن التطبيق الآن خيار اكتشاف اللغة تلقائيًا باستخدام:
- نص المستخدم: للكشف عن لغة النص
- ملف الصوت المرجعي: للكشف عن لغة الكلام إن كان ذلك مدعومًا
- اللغة المختارة يدويًا إذا لم يتم اكتشافها بنجاح

### مثال لغات مدعومة
- `ar` = العربية
- `en` = الإنجليزية
- `fr` = الفرنسية
- `es` = الإسبانية
- `bm` = البامبارا (Bambara)

### ملاحظة مهمة عن البامبارا
نموذج التوليد قد لا يدعم جميع اللغات بشكل كامل في كل نسخة من TTS، لذلك:
- تأكد أن النموذج المستخدم يدعم اللغة المطلوبة
- في بعض الحالات قد تحتاج إلى تمرير رمز اللغة يدويًا
- إذا لم يدعم النموذج البامبارا بشكل مباشر، فقد يلزم استخدام نموذج متعدد اللغات يدعمها أو تعديل إعدادات اللغة داخل التطبيق

## النموذج المستخدم
النموذج الموصى به في هذا التطبيق هو:
```text
tts_models/multilingual/multi-dataset/xtts_v2
```

هذا النموذج يدعم العديد من اللغات، ومن ضمنها بعض اللغات متعددة اللغات، وقد يكون مناسبًا لاستخدام البامبارا إذا كان الدعم متاحًا في النسخة المستخدمة.

## ملاحظات هامة
- أول تشغيل قد يستغرق وقتًا طويلًا بسبب تحميل النموذج.
- إذا كان الجهاز لديك يملك GPU ستعمل العملية أسرع.
- يفضل استخدام ملفات صوتية مرجعية بطول 3-10 ثوانٍ فقط.
- كلما كانت جودة الصوت المرجعي أفضل، كانت جودة الاستنساخ أفضل.

## استكشاف الأخطاء
إذا ظهر خطأ مثل `No module named TTS` أو `torch`:
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

إذا ظهرت مشكلة في تحميل النموذج:
- تأكد من اتصال الإنترنت
- تأكد من أن النموذج المطلوب متاح في الخادم
- حاول تشغيله مرة أخرى بعد التأكد من توفر الشبكة

إذا تعذر اكتشاف اللغة تلقائيًا:
- اطلب من المستخدم اختيار اللغة يدويًا
- تأكد أن النص غير فارغ
- تأكد أن الملف الصوتي واضح ومسموع

## مثال عملي لتحديد اللغة تلقائيًا
```python
from langdetect import detect


def detect_language(text: str):
    try:
        return detect(text)
    except Exception:
        return None

text = "Mali ye bamakan tɔgɔ la"
print(detect_language(text))  # قد يكتشف البامبارا أو لغة أخرى حسب النص
```
