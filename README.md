# Bam-kanladege

تطبيق بسيط لاستنساخ الصوت باستخدام Gradio و TTS.

## ما الذي يفعله التطبيق؟
- يطلب منك رفع ملف صوتي مرجعي (3-10 ثواني)
- يطلب منك كتابة نص ليُقال
- ثم يولّد ملف صوتي جديدًا بنفس نبرة الصوت المرجعي

## المتطلبات
- Python 3.9+
- pip

## تثبيت المكتبات
```bash
pip install -r requirements.txt
```

## التشغيل
```bash
python app.py
```

ثم افتح الرابط الذي يظهر في الطرفية، عادةً:
- http://127.0.0.1:7860

## ملاحظات مهمة
- أول تشغيل قد يستغرق وقتًا طويلًا بسبب تحميل النموذج.
- النموذج المستخدم في المثال هو: `tts_models/multilingual/multi-dataset/xtts_v2`
- الملفات الناتجة تُحفظ داخل مجلد `outputs/`
- إذا كان الجهاز لديك يملك GPU ستعمل العملية أسرع.

## استكشاف الأخطاء
إذا ظهر خطأ مثل `No module named TTS` أو `torch`:
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

إذا ظهرت مشكلة في تحميل النموذج، تأكد من اتصال الإنترنت لأنه يحتاج إلى تنزيل النموذج أول مرة.

## مشروعك الأصلي
هذا التطبيق يعالج المشكلة الأساسية في README السابق: كان الملف مختلطًا بين أمثلة متعددة، وهو غير قابل للتشغيل كـ app واحد. الآن تم تنظيم المشروع كـ تطبيق ويب عملي وقابل للاستخدام.
